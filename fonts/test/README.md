# Font uji (Tahap 1)

Hanya untuk uji render. Diambil dari repo [google/fonts](https://github.com/google/fonts), lisensi SIL Open Font License (lihat `OFL.txt` di tiap folder).

- `lato/` — Lato Regular dan Bold (file statis)
- `playfairdisplay/` — Playfair Display (variable font, dipakai instance default)

Daftar font terkurasi dibuat di Tahap 3 dan menggantikan folder ini.
